# 48시간 금고

태블릿용 투자 판단 기록 웹앱 (`index.html` 파일 하나).

- 편향 체크리스트 8개 중 '예'가 3개 이상이면 48시간 잠금
- 48시간 후 최종 결정(매수 / 보류 / 포기)과 한 줄 메모 기록
- 결정 일지, 백업(JSON/CSV) 내보내기·불러오기

## 원칙
- 매수·매도를 추천하거나 결정하지 않음
- 증권사·은행 연결, 자동 주문·이체 없음
- 로그인·개인정보 입력란 없음
- 기록은 브라우저(localStorage)에만 저장, 외부 전송 없음 (CSP로 네트워크 요청 차단)
- 백업 파일(`vault48-backup-*`, `*.json`, `*.csv`)은 `.gitignore`로 커밋 제외

## 여는 법
GitHub 저장소 Settings → Pages → Branch 선택 → `/ (root)` 저장 후 표시되는 주소로 접속.
